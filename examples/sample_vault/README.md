# Fictional presentation sample

This static sample shows ordinary Apex notes and a native Apex Classes Base.
All class facts, UUIDs and human fields are fictional. Both examples use Boolean
false for Technical Debt, matching the new unchecked default. DemoExtension also
illustrates a human review status and alias. No Salesforce audit dates
or dependency facts are invented.

There is no .obforce state or recovery material. This is a read-only presentation
example, not a build/sync target. Do not adopt it as a managed vault. To exercise
commands, follow the [quickstart](../../docs/QUICKSTART.md) in a new external
workspace. Open no real vault on behalf of this example.

The [dashboard guide](../../docs/DASHBOARDS.md) explains ownership, customization
and unavailable native preview evidence. Opening a copy yourself requires no
community plugins or Obsidian CLI. Ordinary Markdown is useful independently.
